# Barni Bot

Telegram-бот для FACEIT CS2: статистика, теги біля ніків, рейтинг компанії та підсумки за командою. Node.js 22.13+; PNG-картки через resvg та sharp. Інтерфейс українською.

## Запуск

1. Створи бота через [@BotFather](https://t.me/BotFather), отримай токен.
2. Створи Server-side API key у [FACEIT Developer Portal](https://developers.faceit.com/).
3. Скопіюй `.env.example` у `.env`, локально заповни `TELEGRAM_BOT_TOKEN` і `FACEIT_API_KEY`. Не публікуй ці значення. `.env` і `data/` виключені з Git.
4. За бажанням укажи `TELEGRAM_CHAT_ID`, щоб обмежити групові команди одним чатом. Без нього бот працює в групах, до яких його додали.
5. `npm ci`, потім `npm start`. Потрібен постійно ввімкнений комп’ютер або сервер із доступом до Telegram і FACEIT.
6. Додай бота адміністратором групи з правом керувати тегами. Не потрібно підвищувати гравців до адміністраторів або вимикати privacy mode.
7. Кожен учасник виконує `/link свій_FACEIT_нік` у групі. Якщо профіль прив’язано в особистих повідомленнях, `/stats` у групі додає його до її рейтингу та тегів.

Не запускай дві копії з одним токеном або файлом даних. Якщо встановлений webhook, бот зупиниться з поясненням — не видалятиме чужу конфігурацію автоматично.

## Команди

| Команда | Результат |
| --- | --- |
| `/link nickname` або URL профілю | Прив’язка до Telegram ID |
| `/unlink` | Видалення прив’язки, даних гравця та встановлених тегів |
| `/stats` | Картка, кнопки «Сьогодні», «Останні 20», «За весь час» |
| `/last` | Результат, карта, K/D/A, час і посилання останнього матчу |
| `/top` | Учасники чату за поточним Elo |
| `/top day`, `/top week` | Пояснення: приріст Elo недоступний без історії рейтингу |
| `/summary`, `/summary yesterday` | Підсумок сьогодні / учора |
| `/records` | Поточний рівень і серія перемог за останніми 20 матчами FACEIT |
| `/tags on`, `/tags off` | Налаштування адміністратора групи |
| `/status` | Свіжість даних і причина помилки тегу |

Автоматичних підсумків або сповіщень у чат **немає**. Кнопки картки перемикає лише той, хто її відкрив. Прив’язка за ніком — самостійне декларування профілю, не перевірка володіння через OAuth. Один FACEIT-профіль може бути прив’язаний лише до одного Telegram ID у цій копії бота.

## Матчі, доба та Elo

- Ігровий день — від **07:00 до 07:00** наступної дати в `Europe/Kyiv` (з переходами літнього часу); часовий пояс змінюється через `TIMEZONE`. До 07:00 матчі належать попередній даті. Це правило спільне для `/stats`, `/summary`, `/summary yesterday`.
- Матч належить дню **завершення**. Скасовані матчі виключаються, дублікати прибираються за match ID. Історія за останні 3 дні завантажується з пагінацією; останні 20 запитуються окремо, включно зі старішими матчами.
- В офіційній схемі історії FACEIT немає гарантованої зміни Elo за матч. Бот **не** множить перемоги/поразки на 25 і не видає зміну профілю за Elo конкретного матчу.
- Матчі та детальна статистика запитуються напряму у FACEIT для поточного запиту/циклу. Після обробки тимчасовий список матчів очищається. На диск матчі, статистика, матчеві знімки Elo та рекорди не записуються.
- `/summary` показує поточне Elo, матчі та W/L за день. Денний приріст Elo і топ приросту недоступні через офіційне джерело.
- Загальна статистика береться з FACEIT lifetime. K/D за вибіркою — сума вбивств / сума смертей. Детальні показники беруться з першого раунду статистики матчу (звичайний CS2 BO1); багатокартові серії потребують окремого розширення.

## Теги

Приклад: `2150 ELO` — тільки поточний рейтинг FACEIT, без кількості матчів, приросту чи інших показників.

Telegram обмежує тег 16 символами, забороняє emoji і не дає задати власний колір. Колірні позначки результатів є в повідомленнях статистики. Для редагованих ботом адміністраторів використовується custom title; власник групи та недоступні для редагування адміністратори матимуть пояснення в `/status`. Бот не змінює права учасників. Увімкнені теги замінюють поточний тег/титул; вимкнення очищає встановлені ботом теги, попередній ручний текст не відновлюється.

Цільовий цикл — 60 секунд. При незмінному тексті Telegram-запит на запис не надсилається. Збої API, великі групи та запити детальної статистики можуть подовжити цикл. Дані старші 3 хвилин не використовуються для нового запису тегу; попередній тег лишається, свіжість доступна через `/status`. При rate limit є пауза; помилки тегів повторюються через 5 хвилин.

## Зберігання й перевірка

Стан зберігається атомарно в `data/state.json`, offset Telegram, прив’язки Telegram → FACEIT, налаштування груп, стан тегів/party. Матчі та історія Elo не зберігаються. Старі локальні матчі, статистика та історія Elo автоматично видаляються зі стану при запуску версії 2+. Зберігай резервну копію `data/` перед перенесенням. Пошкоджений файл не перезаписується. Розраховано на один процес та невелику групу друзів; великим групам потрібні база даних і черга запитів.

```sh
npm run check
npm test
```

Тести не потребують ключів і не роблять зовнішніх запитів: межі дня, літній час, відсутність локальної історії, пагінація, теги, права, помилки API, збереження та інтеграційний сценарій на змодельованих відповідях. Реальні відповіді CS2 та дозволи Telegram треба перевірити після налаштування ключів.

Джерела: [Telegram tags](https://core.telegram.org/bots/api#setchatmembertag), [admin titles](https://core.telegram.org/bots/api#setchatadministratorcustomtitle), [FACEIT Data API](https://docs.faceit.com/api/data/).


## Party, порівняння й тимчасові теги

- `/party` — створює один активний збір на групу, автор одразу в складі. Кнопки «Я граю» і «Вийти» доступні кожному учаснику; максимум 5 людей без дублікатів. Закриває автор або адміністратор. Повторна команда оновлює існуючий збір. Для участі FACEIT не обов’язковий; AVG ELO рахується лише за тими, чий прив’язаний профіль зараз доступний.
- `/compare` у відповідь на повідомлення іншого гравця — порівняння ваших прив’язаних профілів. `/compare FACEIT_нік` — порівняння з довільним профілем. Поточні ELO/LVL і статистика останніх 20 матчів: WR, K/D, AVG K, ADR, HS. Порядок значень — лівий / правий гравець. Матчі беруться з FACEIT й не зберігаються.
- `/tag 5 AWP king` у відповідь на повідомлення — **будь-який учасник** безкоштовно змінює тег іншому гравцю на 5 хвилин. Без відповіді команда змінює свій тег. FACEIT-прив’язка для цієї команди не потрібна.
- Тривалість 1–60 хвилин, текст 1–16 символів без emoji та прихованих символів. Нова зміна замінює попередню і запускає строк заново. Статистика не затирає тимчасовий тег. Після завершення повертається свіжий FACEIT-тег; для неприв’язаного гравця — попередній текст. У разі недоступності FACEIT спочатку повертається попередній текст.
- Строки тегів і активний склад party переживають перезапуск, не містять історії матчів. Відновлення перевіряється в основному циклі (звичайно до 20 секунд після дедлайну; запити API можуть затримати перевірку). Якщо Telegram не дозволяє відновлення, бот повторює спробу через хвилину. Після запуску прострочені теги відновлюються автоматично.
- `/tags off` від адміністратора вимикає та очищає всі теги бота, включно з тимчасовими. Титул власника групи та недоступних для редагування адміністраторів Telegram змінювати не дозволяє.


### Текст party

`/party Збираю стак на 19:00` показує повідомлення над складом. До 200 символів, можна кілька рядків. Текст можна змінити повторною командою від автора збору або адміністратора; склад при цьому зберігається. Звичайна `/party` оновлює збір, не видаляючи текст. Повідомлення зберігається після перезапуску.


## Форма, карти стаку, запасні та нагадування

- `/form` — форма власного профілю за останні 10 проти попередніх 10 матчів. У відповідь іншому гравцю — його форма. Показники ADR, K/D, AVG K і WR з різницею; зміна WR — у відсоткових пунктах. Якщо матчів менше 20, показується фактична вибірка. Дані беруться одним запитом статистики гравця (з пагінацією за потреби) й не зберігаються на диск.
- `/taglist` — список усіх тимчасових тегів у поточному чаті: гравець, текст, автор зміни та час до завершення. Прострочені теги, які ще не відновилися через помилку Telegram, позначаються окремо.
- У картці `/party` автоматично з’являються три карти за останніми 20 матчами кожного гравця основного складу. Спочатку сортування за кількістю гравців, які грали карту, потім за середнім WR. WR усереднюється за гравцями; це не статистика лише спільних матчів. Запасні в ці розрахунки не входять. Неприв’язані або недоступні профілі не вигадуються — у покритті карти видно, для скількох гравців є дані. Кеш вибірок — тільки в пам’яті на 2 хвилини.
- Кнопка «Запасний» додає до черги (до 10 людей). Якщо гравець основного складу виходить або стає запасним, перший інший запасний автоматично займає місце. «Вийти» прибирає користувача з обох списків.
- Час `HH:mm` у `/party Збираю стак на 19:00` задає найближчий майбутній старт за часовим поясом бота (`Europe/Kyiv` за замовчуванням). Якщо цей час сьогодні вже минув — старт завтра. Дата й час показуються в картці. Перед стартом є одне нагадування у групі зі згадкою складу та запасних: за 10 хвилин, або в час старту, якщо збір створено менш ніж за 10 хвилин. Бот має працювати; нагадування перевіряються у циклі обробки й можуть затриматися на час запитів до API. Після тривалого простою (понад 5 хвилин після початку) застаріле нагадування пропускається.
- Склад, черга та строк нагадування переживають перезапуск. Закриття збору скасовує нагадування. Зміна лише опису з тим самим часом не повторює його; зміна часу переносить нагадування. Текст без часу прибирає розклад.

Браузерний збір Rating/Swing прибрано. Бот використовує тільки офіційний FACEIT Data API; Chrome та Playwright не потрібні.


## Картка статистики

`/stats` надсилає PNG із аватаром FACEIT, ніком, поточними LVL/Elo, місцем у країні профілю та регіоні. Кнопки «Сьогодні», «Останні 20», «За весь час» оновлюють зображення в тому самому повідомленні. Картку може перемикати її власник; іншому учаснику бот пропонує власну `/stats` зі згадкою.

За вибраний період: AVG K/D/A (цілі числа), K/D (сума kills / сума deaths), ADR, HS, K/R, матчі, W/L, WR і останні п’ять результатів (новіші ліворуч). Lifetime показує доступні загальні K/D, K/R, HS і серії; відсутні дані позначаються «—». Рейтинг і аватар завжди поточні. При нульовій вибірці немає вигаданих AVG або WR. Неповне покриття позначається внизу картки. Недоступність рейтингу чи аватара не заважає показати решту даних.

Використовується тільки офіційний FACEIT Data API та аватар з FACEIT CDN. Браузерний транспорт, недокументований match-rounds і Rating/Swing прибрано. Точна денна зміна Elo з цього API недоступна, тому у підсумку її не показуємо. Матчі, ранги й зображення на диск не зберігаються. PNG відправляється прямо з пам’яті через multipart Telegram Bot API; потрібен дозвіл надсилати фото в чат. Якщо генерація не вдалася, бот надсилає текстову статистику.

Підтримуються macOS і Linux з Node.js 22.13+; встановлення залежностей через `npm ci` на цільовій машині. Chrome/Xvfb не потрібні. Noto Sans (українська й латинка) та OFL-ліцензія включені в `assets/fonts`, тому встановлювати системні шрифти не потрібно.

## Картки команд

`/top`, `/compare`, `/last`, `/summary` (також `yesterday`) та `/form` надсилають PNG у стилі `/stats`, з прямими зовнішніми кутами. `/party`, допомога, статус і теги залишаються текстом.

- `/top`: аватари, місця, ніки, рівень та поточний Elo; перші три місця виділені. До 10 гравців на зображення; великі списки надсилаються кількома сторінками без втрати позицій.
- `/summary`: нік, поточний Elo, матчі, W/L і WR; лише учасники, які грали у вибраний ігровий день (07:00–07:00). Сортування за поточним Elo. WR рахується лише за відомими результатами. Денна зміна Elo не вигадується.
- `/compare`: два профілі поруч, вибірки до 20 матчів. Кращі доступні показники зелені, однакові або відсутні — без підсвічення. У K/D/A порівнюються окремі компоненти; менше смертей — краще. Округлення K/D/A до цілих, нічия за показаною точністю не виділяється.
- `/last`: карта, WIN/LOSS, рахунок з боку гравця, назви команд, K/D/A, K/D, ADR, HS, K/R, мультикіли, час/тривалість/регіон. Кнопка відкриває матч. Elo і рівень — поточні.
- `/form`: попередні до 10 проти останніх до 10, ADR/KD/AVG K/WR зі зміною; WR — у відсоткових пунктах. Неповна вибірка позначається, відсутні дані не стають нулями.

Аватари завантажуються з FACEIT CDN, одночасно до чотирьох. Якщо аватар недоступний — ініціал. Генерація й фото тільки в пам’яті, без збереження історії. Якщо PNG згенерувати не вдалося — текстова відповідь із тими самими кнопками. Нових npm-залежностей не потрібно.

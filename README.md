# Barni Bot

Telegram-бот для FACEIT CS2: статистика, теги біля ніків, рейтинг компанії та підсумки за командою. Node.js 22.13+; PNG-картки через resvg та sharp. Інтерфейс українською.

## Запуск

1. Створи бота через [@BotFather](https://t.me/BotFather), отримай токен.
2. Створи Server-side API key у [FACEIT Developer Portal](https://developers.faceit.com/).
3. Скопіюй `.env.example` у `.env`, локально заповни `TELEGRAM_BOT_TOKEN` і `FACEIT_API_KEY`. Не публікуй ці значення. `.env` і `data/` виключені з Git.
4. За бажанням укажи `TELEGRAM_CHAT_ID`, щоб обмежити групові команди одним чатом. Без нього бот працює в групах, до яких його додали.
5. `npm ci`, потім `npm start`. Потрібен постійно ввімкнений комп’ютер або сервер із доступом до Telegram і FACEIT.
6. Додай бота адміністратором групи з правом керувати тегами. Не потрібно підвищувати гравців до адміністраторів або вимикати privacy mode.
7. Кожен учасник виконує `/link свій_FACEIT_нік` у групі. Якщо профіль прив’язано в особистих повідомленнях, `/stats` у групі додає його до її рейтингу та тегів.

Не запускай дві копії з одним токеном або файлом даних. Якщо встановлений webhook, бот зупиниться з поясненням — не видалятиме чужу конфігурацію автоматично.

## Команди

| Команда | Результат |
| --- | --- |
| `/link nickname` або URL профілю | Прив’язка до Telegram ID |
| `/unlink` | Видалення прив’язки, даних гравця та встановлених тегів |
| `/stats` | Картка, кнопки «Сьогодні», «Останні 20», «За весь час» |
| `/last` | Результат, карта, K/D/A, Δ Elo, час і посилання останнього матчу |
| `/teams @user1 … @user10` | Вибрані Telegram-гравці → баланс двох п’ятірок за Elo |
| `/top` | Учасники чату за поточним Elo |
| `/top day`, `/top week` | Приріст Elo: сума дельт матчів Analyser або власний трекінг |
| `/summary`, `/summary yesterday` | Підсумок сьогодні / учора |
| `/maps` | WR, ADR, K/D та кількість матчів за картами за 30 ігрових днів |
| `/bestmatch` | Найкращі матчі за фрагами, ADR та K/D за 30 ігрових днів |
| `/records` | Поточний рівень і серія перемог за останніми 20 матчами FACEIT |
| `/tags on`, `/tags off` | Налаштування адміністратора групи |
| `/status` | Свіжість даних і причина помилки тегу |

Автоматичних підсумків або сповіщень у чат **немає**. Кнопки картки перемикає лише той, хто її відкрив. Прив’язка за ніком — самостійне декларування профілю, не перевірка володіння через OAuth. Один FACEIT-профіль може бути прив’язаний лише до одного Telegram ID у цій копії бота.

## Матчі, доба та Elo

- Ігровий день — від **07:00 до 07:00** наступної дати в `Europe/Kyiv` (з переходами літнього часу); часовий пояс змінюється через `TIMEZONE`. До 07:00 матчі належать попередній даті. Це правило спільне для `/stats`, `/summary`, `/summary yesterday`.
- Матч належить дню **завершення**. Скасовані матчі виключаються, дублікати прибираються за match ID. Історія за останні 3 дні завантажується з пагінацією; останні 20 запитуються окремо, включно зі старішими матчами.
- В офіційній схемі історії FACEIT немає гарантованої зміни Elo за матч. Бот **не** множить перемоги/поразки на 25 і не видає зміну профілю за Elo конкретного матчу.
- Матчі та детальна статистика запитуються напряму у FACEIT для поточного запиту/циклу. Після обробки тимчасовий список матчів очищається. На диск матчі та їхня статистика не записуються. Зберігаються власні спостереження Elo і денні початкові/кінцеві значення.
- `/summary` показує поточне Elo, матчі та W/L за день. За наявності повних даних Analyser денний приріст і топ приросту рахуються як сума дельт матчів. Якщо їх бракує — використовується власний трекінг із `~`.
- Загальна статистика береться з FACEIT lifetime. K/D за вибіркою — сума вбивств / сума смертей. Детальні показники беруться з першого раунду статистики матчу (звичайний CS2 BO1); багатокартові серії потребують окремого розширення.

## Теги

Приклад: `2438 ELO | ↑4242` — поточний рейтинг та максимальний, зафіксований ботом. У тегу немає кількості матчів або денного приросту. Для значень довших за чотири цифри пробіли скорочуються до ліміту 16 символів.

Telegram обмежує тег 16 символами, забороняє emoji і не дає задати власний колір. Колірні позначки результатів є в повідомленнях статистики. Для редагованих ботом адміністраторів використовується custom title; власник групи та недоступні для редагування адміністратори матимуть пояснення в `/status`. Бот не змінює права учасників. Увімкнені теги замінюють поточний тег/титул; вимкнення очищає встановлені ботом теги, попередній ручний текст не відновлюється.

Цільовий цикл — 60 секунд. При незмінному тексті Telegram-запит на запис не надсилається. Збої API, великі групи та запити детальної статистики можуть подовжити цикл. Дані старші 3 хвилин не використовуються для нового запису тегу; попередній тег лишається, свіжість доступна через `/status`. При rate limit є пауза; помилки тегів повторюються через 5 хвилин.

## Зберігання й перевірка

Стан зберігається атомарно в `data/state.json`, offset Telegram, прив’язки Telegram → FACEIT, налаштування груп, стан тегів/party. Матчі не зберігаються; з версії 7 зберігається максимум Elo та денні початкові/кінцеві спостереження за останні 32 ігрові дні. Стара історія матчів і метрик видаляється при міграції; поточні спостереження Elo зберігаються за новою схемою власного трекінгу. Зберігай резервну копію `data/` перед перенесенням. Пошкоджений файл не перезаписується. Розраховано на один процес та невелику групу друзів; великим групам потрібні база даних і черга запитів.

```sh
npm run check
npm test
```

Тести не потребують ключів і не роблять зовнішніх запитів: межі дня, літній час, відсутність локальної історії, пагінація, теги, права, помилки API, збереження та інтеграційний сценарій на змодельованих відповідях. Реальні відповіді CS2 та дозволи Telegram треба перевірити після налаштування ключів.

Джерела: [Telegram tags](https://core.telegram.org/bots/api#setchatmembertag), [admin titles](https://core.telegram.org/bots/api#setchatadministratorcustomtitle), [FACEIT Data API](https://docs.faceit.com/api/data/).


## Party, порівняння й тимчасові теги

- `/party` — створює один активний збір на групу, автор одразу в складі. Кнопки «Я граю» і «Вийти» доступні кожному учаснику; максимум 5 людей без дублікатів. Закриває автор або адміністратор. Повторна команда оновлює існуючий збір. Для участі FACEIT не обов’язковий; AVG ELO рахується лише за тими, чий прив’язаний профіль зараз доступний.
- `/compare` у відповідь на повідомлення іншого гравця — порівняння ваших прив’язаних профілів. `/compare FACEIT_нік` — порівняння з довільним профілем. Поточні ELO/LVL і статистика останніх 20 матчів: WR, K/D, AVG K, ADR, HS. Порядок значень — лівий / правий гравець. Матчі беруться з FACEIT й не зберігаються.
- `/tag 5 AWP king` у відповідь на повідомлення — **будь-який учасник** безкоштовно змінює тег іншому гравцю на 5 хвилин. Без відповіді команда змінює свій тег. FACEIT-прив’язка для цієї команди не потрібна.
- Тривалість 1–60 хвилин, текст 1–16 символів без emoji та прихованих символів. Нова зміна замінює попередню і запускає строк заново. Статистика не затирає тимчасовий тег. Після завершення повертається свіжий FACEIT-тег; для неприв’язаного гравця — попередній текст. У разі недоступності FACEIT спочатку повертається попередній текст.
- Строки тегів і активний склад party переживають перезапуск, не містять історії матчів. Відновлення перевіряється в основному циклі (звичайно до 20 секунд після дедлайну; запити API можуть затримати перевірку). Якщо Telegram не дозволяє відновлення, бот повторює спробу через хвилину. Після запуску прострочені теги відновлюються автоматично.
- `/tags off` від адміністратора вимикає та очищає всі теги бота, включно з тимчасовими. Титул власника групи та недоступних для редагування адміністраторів Telegram змінювати не дозволяє.


### Текст party

`/party Збираю стак на 19:00` показує повідомлення над складом. До 200 символів, можна кілька рядків. Текст можна змінити повторною командою від автора збору або адміністратора; склад при цьому зберігається. Звичайна `/party` оновлює збір, не видаляючи текст. Повідомлення зберігається після перезапуску.


## Форма, карти стаку, запасні та нагадування

- `/form` — форма власного профілю за останні 10 проти попередніх 10 матчів. У відповідь іншому гравцю — його форма. Показники ADR, K/D, AVG K і WR з різницею; зміна WR — у відсоткових пунктах. Якщо матчів менше 20, показується фактична вибірка. Дані беруться одним запитом статистики гравця (з пагінацією за потреби) й не зберігаються на диск.
- `/taglist` — список усіх тимчасових тегів у поточному чаті: гравець, текст, автор зміни та час до завершення. Прострочені теги, які ще не відновилися через помилку Telegram, позначаються окремо.
- У картці `/party` автоматично з’являються три карти за 30 ігровими днями Analyser, без нього — за останніми 20 матчами кожного гравця основного складу. Спочатку сортування за кількістю гравців, які грали карту, потім за середнім WR. WR усереднюється за гравцями; це не статистика лише спільних матчів. Запасні в ці розрахунки не входять. Неприв’язані або недоступні профілі не вигадуються — у покритті карти видно, для скількох гравців є дані. Кеш вибірок — тільки в пам’яті на 2 хвилини.
- Кнопка «Запасний» додає до черги (до 10 людей). Якщо гравець основного складу виходить або стає запасним, перший інший запасний автоматично займає місце. «Вийти» прибирає користувача з обох списків.
- Час `HH:mm` у `/party Збираю стак на 19:00` задає найближчий майбутній старт за часовим поясом бота (`Europe/Kyiv` за замовчуванням). Якщо цей час сьогодні вже минув — старт завтра. Дата й час показуються в картці. Перед стартом є одне нагадування у групі зі згадкою складу та запасних: за 10 хвилин, або в час старту, якщо збір створено менш ніж за 10 хвилин. Бот має працювати; нагадування перевіряються у циклі обробки й можуть затриматися на час запитів до API. Після тривалого простою (понад 5 хвилин після початку) застаріле нагадування пропускається.
- Склад, черга та строк нагадування переживають перезапуск. Закриття збору скасовує нагадування. Зміна лише опису з тим самим часом не повторює його; зміна часу переносить нагадування. Текст без часу прибирає розклад.

Браузерний збір Rating/Swing прибрано. Бот використовує офіційний FACEIT Data API та необов’язковий Faceit Analyser; Chrome та Playwright не потрібні.


## Картка статистики

`/stats` надсилає PNG із аватаром FACEIT, ніком, поточними LVL/Elo, місцем у країні профілю та регіоні. Кнопки «Сьогодні», «Останні 20», «За весь час» оновлюють зображення в тому самому повідомленні. Картку може перемикати її власник; іншому учаснику бот пропонує власну `/stats` зі згадкою.

За вибраний період: AVG K/D/A (цілі числа), K/D (сума kills / сума deaths), ADR, HS, K/R, матчі, W/L, WR і останні п’ять результатів (новіші ліворуч). Lifetime показує доступні загальні K/D, K/R, HS і серії; відсутні дані позначаються «—». Рейтинг і аватар завжди поточні. При нульовій вибірці немає вигаданих AVG або WR. Неповне покриття позначається внизу картки. Недоступність рейтингу чи аватара не заважає показати решту даних.

Використовується тільки офіційний FACEIT Data API та аватар з FACEIT CDN. Браузерний транспорт, недокументований match-rounds і Rating/Swing прибрано. Офіційний API не дає точних Elo-delta матчів: їх доповнює необов’язковий Faceit Analyser. Без нього показується зміна за власними спостереженнями профілю. Матчі, ранги й зображення на диск не зберігаються. PNG відправляється прямо з пам’яті через multipart Telegram Bot API; потрібен дозвіл надсилати фото в чат. Якщо генерація не вдалася, бот надсилає текстову статистику.

Підтримуються macOS, Linux і Windows з Node.js 22.13+ та npm 10+; встановлення залежностей через `npm ci` на цільовій машині. Chrome/Xvfb не потрібні. Noto Sans (українська й латинка) та OFL-ліцензія включені в `assets/fonts`, тому встановлювати системні шрифти не потрібно.

## Картки команд

`/top`, `/compare`, `/last`, `/summary` (також `yesterday`), `/form`, `/maps` та `/bestmatch` надсилають PNG у стилі `/stats`, з прямими зовнішніми кутами. `/party`, допомога, статус і теги залишаються текстом.

- `/top`: аватари, місця, ніки, рівень та поточний Elo; перші три місця виділені. До 10 гравців на зображення; великі списки надсилаються кількома сторінками без втрати позицій.
- `/summary`: нік, поточний Elo, матчі, W/L і WR; лише учасники, які грали у вибраний ігровий день (07:00–07:00). Сортування за поточним Elo. WR рахується лише за відомими результатами. Денна зміна — сума дельт Analyser, або власний трекінг із `~`, без припущень ±25 за матч.
- `/compare`: два профілі поруч, вибірки до 20 матчів. Кращі доступні показники зелені, однакові або відсутні — без підсвічення. У K/D/A порівнюються окремі компоненти; менше смертей — краще. Округлення K/D/A до цілих, нічия за показаною точністю не виділяється.
- `/last`: карта, WIN/LOSS, рахунок з боку гравця, назви команд, K/D/A, K/D, ADR, HS, K/R, мультикіли, час/тривалість/регіон. Кнопка відкриває матч. Elo і рівень — поточні.
- `/form`: попередні до 10 проти останніх до 10, ADR/KD/AVG K/WR зі зміною; WR — у відсоткових пунктах. Неповна вибірка позначається, відсутні дані не стають нулями.

Аватари завантажуються з FACEIT CDN, одночасно до чотирьох. Якщо аватар недоступний — ініціал. Генерація й фото тільки в пам’яті, без збереження історії. Якщо PNG згенерувати не вдалося — текстова відповідь із тими самими кнопками. Нових npm-залежностей не потрібно.

## Встановлення на Linux, macOS та Windows

Потрібні Node.js 22.13+ та npm 10+. На цільовій машині:

```sh
npm ci --include=optional
npm start
```

`.npmrc` вмикає потрібні optional dependencies: npm обирає бінарні пакети `sharp` і `resvg` під поточну ОС та процесор. Не перенось `node_modules` між різними системами; встановлюй залежності на кожній машині зі спільного `package-lock.json`.

`npm start` завантажує `.env` із кореня проєкту без CLI-прапорця `--env-file`. Якщо бібліотеки зображень недоступні, бот відповідає текстом замість карток.

## Команди 5v5 через Telegram-згадки

`/teams @user1 @user2 @user3 @user4 @user5 @user6 @user7 @user8 @user9 @user10` — вибери десять учасників через Telegram `@`. Підтримуються звичайні username та згадки користувача без username (Telegram `text_mention`). Кожен має прив’язати FACEIT через `/link`; для пошуку за username гравець має бути відомий боту в цьому чаті (`/link` або `/stats` у групі).

Команда звіряє актуальні username й участь у чаті через `getChatMember`, не вгадує Telegram ID з імені. Якщо когось не знайдено, немає FACEIT-прив’язки або обрано дублікати — розподіл не публікується. Доступна кожному учаснику групи; автора команди автоматично не додає, party та запасних не змінює.

Беруться свіжі Elo саме десяти вибраних профілів. Перебираються всі 126 різних поділів 5v5 та вибирається мінімальна різниця сум Elo (а отже, середніх). Це баланс за Elo, не прогноз перемоги або оцінка ролей. Відповідь — картка з аватарами, FACEIT-ніками, Elo, середніми обох команд і різницею; у підписі клікабельні Telegram-згадки. Без робочого рендера надсилається текст.

## Власне відстеження Elo та MAX

Від кожного свіжого профілю зберігаємо спостережене Elo, час, максимум від початку трекінгу та денні початкові/кінцеві значення. Історія матчів не записується. Останні 32 ігрові дні зберігаються для підсумків; загальний MAX не скидається й переживає перезапуск. При `/unlink` цей профіль і його трекінг видаляються.

Без підключеного Analyser MAX — **найбільше значення, яке бачив бот**. З Analyser береться більше з його `highest_elo` для CS2 та власного відстеженого максимуму. Дата початку є в картках. Перший день починається з поточного Elo й позначається `~`; бот не знає, що було до його запуску. При безперервному спостереженні (останній знімок не старіший за 3 хвилини) о 07:00 переноситься попередній Elo як нова денна база. Якщо бот пропустив межу дня — новий період знову неповний. Це запасний розрахунок за різницею спостережень профілю. Якщо підключено Analyser і відомі дельти всіх матчів дня — використовується їхня сума за часом завершення матчів.

MAX і денна Δ є в `/stats`, `/last`, `/form`, `/compare` для відстежуваних профілів, `/top` і `/summary`. Для сторонніх профілів без трекінгу — `—`. `/top day` сортує за денною зміною, `/top week` — за зміною протягом доступної частини останніх семи ігрових днів. При неповному покритті залишається `~`; невідомі дні не вважаються нульовими матчами/дельтами.

Тег: `2438 ELO | ↑4242` (рівно 16 символів). У ньому лише поточний Elo та відстежений MAX, без денної зміни. Тимчасовий `/tag` як і раніше діє до свого завершення; після нього повертається актуальний FACEIT-тег.

## Faceit Analyser

Додай `FACEIT_ANALYSER_API_KEY=...` у локальний `.env` або environment на машині, де запускається бот. Це окремий ключ Faceit Analyser, не FACEIT Data API. Ключ не зберігається у файлі стану, не відображається в картках або помилках.

Підключено `GET https://faceitanalyser.com/api/stats/{FACEIT_UUID}/cs2`: `highest_elo` доповнює MAX у тегах, картках і рейтингу. Зберігаються тільки MAX/MIN, діапазон дат джерела та час перевірки, без історії матчів. Власний MAX, якщо він більший, має пріоритет; поточне Elo завжди береться з FACEIT. Історичні дельти доповнюються з `/api/matches/{FACEIT_UUID}/cs2`.

Кеш MAX — 24 години та зберігається після перезапуску. Єдина черга з інтервалом щонайменше 1.1 секунди виконує запити послідовно; повторні запити до того самого профілю об’єднуються. Запит не повторюється одразу після помилки. Після успішної відповіді без найновішого матчу допускається до трьох оновлень із паузою 2 хвилини, далі — 6 годин. Для 8 профілів сама щоденна перевірка MAX — близько 240 запитів на місяць; історія та додаткові профілі у `/compare` витрачають додаткові запити.

Документація сервісу вказує 1 запит/секунду та 5000 безкоштовних запитів/місяць, далі €1/1000; враховуй використання цього ключа іншими застосунками. Після 401/403/429 або збою працює пауза; попередній MAX та власний трекінг доступні, решта команд продовжує працювати. Історія Analyser не записується на диск. Повний набір дельт дозволяє показати суму за день навіть без локальної ранкової бази. Це Elo саме за матчі; повернення Elo або інші зміни профілю поза матчами в цю суму не входять.

У `/help` та всіх відповідях із даними сервісу є видимий кредит із посиланням **Powered by Faceit Analyser**. На PNG також є назва сервісу й URL. Це обов’язкова умова ключа за [документацією Faceit Analyser](https://faceitanalyser.com/docs).

### Дельти, карти, графік і найкращі матчі

- Один набір останніх матчів Analyser використовується для всіх функцій, лише в оперативній пам’яті. Кеш оновлюється при новому завершеному матчі, зміні поточного Elo, новому ігровому дні або після доби. Кеші обмежені 100 профілями. Холодний старт знову завантажує дані.
- Матчі звіряються за ID з офіційною історією FACEIT за 30 ігрових днів, включно з поточним. Дата визначається офіційним часом завершення; межа — 07:00 у часовому поясі бота. Дублікати не множать Elo, суперечливі дельти лишаються невідомими. Використовуємо сторінки по 500 матчів до виходу за період, максимум 2000 записів; ліміт або неповне покриття явно позначаються. Через некоректну відповідь фільтра дат сервісу відбір періоду виконується після завантаження останніх матчів.
- `/last` показує Δ Elo конкретного матчу. `/stats`, `/summary`, `/top day` і `/top week` використовують суми дельт, лише коли відомі всі матчі відповідного періоду. Якщо хоча б одного бракує — власний трекінг із `~` або `—`, без вигаданих ±25.
- У всіх періодах `/stats` з’являється графік Elo за останні 30 ігрових днів. Точки — Elo після матчів; показується покриття. Без даних — пояснення замість вигаданого графіка. Період графіка не змінюється при перемиканні сьогодні / 20 / за весь час.
- `/maps` показує кількість матчів, WR, ADR і K/D за картами. WR рахується за відомими результатами; K/D — сумарні kills / deaths за доступними парами, ADR — середнє доступних ADR за матч. Карти з менш ніж 5 матчами позначаються як мала вибірка. У `/party` показуються рекомендовані карти: спочатку покриття учасників, потім середній WR за гравцями з мінімум 5 матчами на карту. Це особиста статистика учасників, не лише спільні матчі; ADR у party не показується.
- `/bestmatch` — три категорії за ті самі 30 днів: kills, ADR, K/D; карта, результат, K/D/A та кнопки матчів. Це рекорди вибраного періоду. Відсутній показник не підміняється іншим рейтингом. Неповне покриття підписується.
- `/maps` і `/bestmatch` можна викликати відповіддю на повідомлення прив’язаного гравця. Якщо Analyser недоступний або ключа немає, вони беруть останні 20 матчів з офіційного API та явно показують цей період.

HLTV rating не підміняє FACEIT Rating. Нових залежностей або фонових повідомлень ці функції не додають.
